# 🎉 JARVIS - GUÍA DE INICIO RÁPIDO

## ✅ ¡LISTO PARA USAR!

Tu Jarvis está 100% configurado y listo. Solo tienes que hacer lo siguiente:

---

## 🚀 PASOS SIMPLES

### Paso 1: Descargar la Carpeta

1. Ve a: https://github.com/sandogilh-sketch/jarvis-ai-assistant
2. Haz clic en **Code** (botón verde)
3. Selecciona **Download ZIP**
4. Extrae la carpeta en tu **Escritorio** o **Documentos**

---

### Paso 2: Instalar (PRIMERA VEZ SOLAMENTE)

1. Abre la carpeta `jarvis-ai-assistant`
2. **Doble clic** en: **`install-windows.bat`**
3. Una ventana negra se abrirá
4. Espera a ver: **✅ JARVIS LISTO PARA USAR**
5. Presiona cualquier tecla para cerrar

**⏱️ Toma 5-10 minutos la primera vez**

---

### Paso 3: Iniciar Jarvis (CADA VEZ)

1. Abre la carpeta `jarvis-ai-assistant`
2. **Doble clic** en: **`start-jarvis.bat`**
3. Espera a ver: **✅ Servidor iniciado en puerto 3000**
4. **DEJA ESA VENTANA ABIERTA**
5. **Doble clic** en: **`open-jarvis.bat`**
6. Se abrirá automáticamente tu navegador

---

### Paso 4: ¡USAR JARVIS!

1. Verás la interfaz de Jarvis
2. Ve a la pestaña: **"🎤 Voz"**
3. Haz clic en el botón grande redondo 🎤
4. Dirá: "Escuchando..."
5. **¡HABLA EN ESPAÑOL!**

Para no buscar cada vez:

1. Haz clic derecho en **`start-jarvis.bat`**
2. **"Enviar a"** → **"Escritorio (crear acceso directo)"**
3. Listo! Ahora solo haz doble clic desde el escritorio

## 🆘 PROBLEMAS COMUNES

### ❌ "Node.js no encontrado"
```
→ Descarga: https://nodejs.org/
→ Instala la versión LTS
→ Ejecuta install-windows.bat de nuevo
```

### ❌ "No funciona el micrófono"
```
→ Usa Chrome, Edge o Safari
→ Verifica que hayas dado permisos al navegador
→ Comprueba tu micrófono en Windows
```

### ❌ "Puerto 3000 ocupado"
```
→ Edita start-jarvis.bat
→ Cambia: npm start --port 3001
→ Luego abre: http://localhost:3001
```
