# 🎉 INSTALACIÓN COMPLETADA - WINDOWS

## ✅ Tu Jarvis está listo

Tienes 3 archivos `.bat` para usar:

### 1️⃣ **install-windows.bat** (Una sola vez)
```
Uso: Doble clic para instalar Jarvis
- Verifica Node.js
- Te pide tus tokens
- Instala dependencias
- Crea archivo .env
```

### 2️⃣ **start-jarvis.bat** (Cada vez que quieras usar)
```
Uso: Doble clic para iniciar servidor
- Inicia el servidor en puerto 3000
- Deja la ventana abierta
```

### 3️⃣ **open-jarvis.bat** (Abrir navegador)
```
Uso: Doble clic para abrir en navegador
- Abre http://localhost:3000
- Crea acceso directo para más facilidad
```

---

## 🚀 PRIMER USO - PASO A PASO

### Paso 1: Instalar (Primera vez solamente)
1. Descarga la carpeta `jarvis-ai-assistant`
2. Abre `install-windows.bat` (doble clic)
3. Ingresa tu GitHub Token
4. Ingresa tu Gemini API Key
5. Espera a que termine

### Paso 2: Iniciar Jarvis (Cada vez)
1. Abre `start-jarvis.bat` (doble clic)
2. Espera a ver: ✅ Servidor iniciado
3. Abre `open-jarvis.bat` (doble clic)
4. Se abrirá automáticamente en tu navegador

### Paso 3: Usar Jarvis
1. Ve a la pestaña "🎤 Voz"
2. Haz clic en el botón micrófono
3. ¡HABLA!

## 💡 TIPS PARA WINDOWS

### Crear Acceso Directo en Escritorio
1. Haz clic derecho en `start-jarvis.bat`
2. "Enviar a" → "Escritorio (crear acceso directo)"
3. Renómbralo a "Jarvis"
4. Ahora solo doble clic en el escritorio para iniciar

### Crear Carpeta con todos los Scripts
1. Crea una carpeta "Jarvis" en Documentos
2. Mueve `start-jarvis.bat` y `open-jarvis.bat` ahí
3. Ten todo organizado en un lugar

### Si Puerto 3000 está ocupado
Edita `start-jarvis.bat` y cambia:
```
npm start --port 3001
```

## 🆘 TROUBLESHOOTING

### Error: "Node.js no está instalado"
```
Solución: Descarga desde https://nodejs.org/
Instala y ejecuta install-windows.bat de nuevo
```

### Error: "GITHUB_TOKEN no válido"
```
Solución: Genera nuevo token en https://github.com/settings/tokens
Ejecuta install-windows.bat de nuevo
```

### El puerto 3000 está ocupado
```
Solución: Edita start-jarvis.bat y usa otro puerto (3001, 3002, etc)
```

### No funciona el micrófono
```
Solución:
1. Usa Chrome, Edge o Safari
2. Verifica permisos del navegador
3. Recarga la página (F5)
4. Comprueba que tu micrófono funciona en Windows
```
